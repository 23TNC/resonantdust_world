spans components by nature. Convention: [`../CONVENTIONS.md`](../CONVENTIONS.md). Last updated:

**Status** = the stream's lifecycle, not the session's focus: `open` (in progress) · `done`
(delivered; may have a small hand-off) · `closed` (abandoned/refuted) · `blocked` (needs input).
The continuation hook's notion of the **active** stream is *session-scoped* (which open stream this
session is driving — inferred, not a field here); see [`docs-authority`](docs-authority/README.md) P5.

Everything is a **prim** — one flat `u16` index space, no set nibble, no billboard/light/tile taxonomy; three type lanes (`cast_type`/`receive_type`/`emit_type`) decide what a prim does. `definition_data` allocates **16 px per definition indexed by rotation**, so `base + rotation` subsumes the n/s caster card, the e/w mirror and the 16-cell autotile table — three special cases collapsing into one add. Dissolves all three failures that killed the old system BY CONSTRUCTION: a reference is exactly `u16` so 8 fit a texel ([strip I1](2026-07-31-lighting-strip/issues.md#i1)); the stored value IS the caster identity, so `max`-discards-which is gone ([I2](2026-07-31-lighting-strip/issues.md#i2)); and one slot per light makes every change *(light slot) × (dirty region)*, so the **entire hot/cold axis, the prev-buffers and the class-aware dirty machinery stop existing** ([I5](2026-07-31-lighting-strip/issues.md#i5)). Adjustments made for performance and errors: slots for writing + **one summed map for reading** so the display does 1 fetch not 8 ([F1](2026-07-31-lighting-rework/forks.md#f1)); `RGB10_A2` at ¼ scale, preserving today's 4× overbright, blendable in core WebGL2 ([F2](2026-07-31-lighting-rework/forks.md#f2)); **one draw for all 8 lights**, index from fragment x, **never MRT** ([F3](2026-07-31-lighting-rework/forks.md#f3)); ping-ponged per-unit shadow ([F4](2026-07-31-lighting-rework/forks.md#f4)); gated per-pixel refine ([F5](2026-07-31-lighting-rework/forks.md#f5)); reach derived from intensity by ONE shared function ([F6](2026-07-31-lighting-rework/forks.md#f6)); validate-on-write ([F7](2026-07-31-lighting-rework/forks.md#f7)); recycled indices re-checked ([F9](2026-07-31-lighting-rework/forks.md#f9)); and **every cap counts what it drops** ([F10](2026-07-31-lighting-rework/forks.md#f10)). Three design bugs found in review are carried as acceptance criteria, not notes: the `l > 4` slot split drops light 4 ([I1](2026-07-31-lighting-rework/issues.md#i1)), receiver selection breaks before testing coverage and so resolves a pixel to different surfaces per light ([I2](2026-07-31-lighting-rework/issues.md#i2)), and the span/subframe lanes are biased ([I3](2026-07-31-lighting-rework/issues.md#i3)). Phased so **P3 prices the per-pixel pass BEFORE P4 builds shadows on it** — the opposite of the old stream, which built the refine first and found it cost 9.29 ms of a 10.88 ms pass. Target: moving lights at reach 16 inside 8 ms, from the stripped floor of 0.045 ms/frame. |
