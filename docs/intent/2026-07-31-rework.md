atlas store textures using quadtree packing and power of 2 sizes.  
atlas will store 4 maps for each definition.  So the size in atlas will be
fullframe.span  = (frame.span * 2) (full frame, so all 4 maps arranged in a 2x2 grid will have a span of 2*frame.span)

So if our texture is 128, our frame.span is 1, our fullframe.span is 2, so full frames are 256 square textures saved in our atlas.
So if our texture is 256, our frame.span is 2, our fullframe.span is 4, so full frames are 512 square textures saved in our atlas.

Now the idea becomes that we can run UNITS_PER_TILE^2 = 256 fragments per tile (one per UNIT).

Each fragment can:
Read light at that fragment's tile as light.
Read presence at that fragment's tile as presence.
Read shadow at that fragment's unit as shadow.
Read shadow at that fragment's adjacent units +/- x and +/- y as adjacent.

for l in 0..7:
  if !occludes(light[l], shadow[0][l], presence[0]):
    shadow[0][l] = 0
  if !shadow[0][l]:
    for adj in adjacent[0][l]:
      if occludes(light[l], adj, presence[0]):
        shadow[0][l] = adj
        break
  
  if l >= 4:
    i=2
    ll = (l-4)*2
  else:
    i=1
    ll = l*2
  if !occludes(light[l], shadow[i][ll], shadow[i][ll+1]):
    shadow[i][ll] = 0
  if !shadow[i][ll]:
    for adj in adjacent[i][ll]:
      for r in presence[1..7]:
        if occludes(light[l], adj, r):
          shadow[i][ll] = adj
          break
  
  if !shadow[i][ll] || !shadow[0][l]:
    for t in corridor_walk(light[l]):
      Read presence at tile t as presence_walk
      for c in presence_walk:
        if !shadow[0][l]:
          if occludes(light[l], c, presence[0]):
            shadow[0][l] = c
        if !shadow[i][ll]:
          for r in presence[1..7]:
            if occludes(light[l], c, r):
              shadow[i][ll] = c
        if shadow[i][ll] && shadow[0][l]:
          break



Having populated our shadow we may now conduct the full resolution pass.

for each px:
  Read light at that px's tile as light
  Read presence at that px's tile as presence
  Read shadow at that px's unit as shadow
  Read shadow at that px's adjacent units +/- x and +/- y as adjacent.
  
  for light in 0..7:
    // if tile has our px
    if presence[0].surface.has(px):
      // no shadow
      if !(shadow[0][l]):
        draw(light[l], px, presence[0])
      else:
        // If shadow, then check prim shadow[0][l] if texture occluded
        // the specific px on presence[0] and draw if not.
        draw_shadow(light[l], shadow[0][l], presence[0], px)
    
    if l >= 4:
      i=2
      ll = (l-4)*2
    else:
      i=1
      ll = l*2
    
    // if no caster for this unit
    for r in presence[7..1]:
      // if we have a caster, and it casts onto us
      if (shadow[i][ll]) && (shadow[i][ll+1] == r):
        // If shadow, then check prim shadow[i][ll] if texture occluded
        // the specific px on r and draw if not.
        draw_shadow(light[l], shadow[i][ll], r, px)
        // everything below us is shadowed anyway
        break
      if r.has(px):
        // draw the top most !shadowed px
        draw(light[l], px, r)
        break
