# Texture index — one index of the master tree, not two

_Intent (server/edge). PROPOSED — the destination of
[`work/2026-08-04-content-toml-only`](../../../../work/2026-08-04-content-toml-only/README.md)
[F5](../../../../work/2026-08-04-content-toml-only/forks.md#f5) P5. The move that made this

## The situation

Two indexes scan the same texture master tree and neither knows about the other.

**`/textures-manifest`** ([`tex_manifest.rs`](../../../../../server/edge/src/tex_manifest.rs)) is
built by the edge at boot from `TextureSource::Disk`, re-scanned by a poll, and consumed by the
live client ([`textureManifest.ts`](../../../../../client/webgl/src/textures/textureManifest.ts)).
Per stem it serves `hash`, `maxSize`, `lods`, `maps`, and optionally `span` + `square` (the pow2
packing square) and `grid` + `pad` (a linked atlas's cell grid and per-cell inset).

**`textures/manifest/<type>.json`** is generated by `bin/art manifest` from the same tree and read
by **nobody**. It exists for the future `^r2` resolver, which cannot probe R2 mid-draw and so
needs to know what exists before it asks.

Two indexes of one tree is a second place recording one fact, which the conventions ban outright.
The reason it survived the move rather than being deleted is that it is not a duplicate: it
carries four things `tex_manifest` does not.

## What the art manifest carries alone — measured, 2026-08-04

Almost nothing. Against the live endpoint (228 stems):

| Field | Status | Evidence |
|---|---|---|
| `var_id` / `var_variant` | **already served**, as KEYS not arrays | the wolf's variant folders are stems: `pawn/animal/wolf/124/e`, `…/125/e`, `…/555/e`, … Existence is the key set, which is exactly what a resolver needs to avoid a speculative 404 |
| `part_id` / `part_variants` | **already served**, as the `.N` stem suffix | `pawn/human/female/0/e` (body) and `pawn/human/female/0/e.1` (head) are separate stems |
| `layers` | **already implied** — it *is* the part count | `_layer_count` counts distinct `<part>` across diffuse leaves: wolf 1, female 2, male 2 |
| `subkinds` | **empty for every kind in the tree** | `_override_ints` finds no `<base>.<int>` sibling anywhere; the axis is authored nowhere yet |

`hash` and `maps` overlap, but the hashes are **not** the same value: the edge hashes per STEM
(16 hex, the leaf's own bytes); `bin/art`'s `_kind_hash` hashes per KIND (sha256 over the kind's
master PNGs, truncated to 52 bits). The kind hash is the recipe `art gc` compares against when
deciding what is stale in the bucket, so it cannot be changed to match without moving GC too.

## The intent, and why it is not built yet

**`/textures-manifest` should be the one index** — that goal stands. What the measurement changed
is the work: there are no missing fields to port, so the merge is really "retire the second
producer", and that is blocked on something concrete.

`tex_manifest` is **disk-only**. From its own header: *an R2 source yields an empty manifest — its
manifest is future work, generated offline by `bin/art` alongside the master upload.* In R2 mode
the edge serves nothing, and the offline generator is the documented filler. Deleting it would
remove the only planned index for that mode.

So both survive for now, and they do not conflict: only one produces an index in any given
deployment mode. `bin/art manifest` writes `textures/manifest/<type>.json` — beside the masters,
uploaded with them
([F1](../../../../work/2026-08-04-content-toml-only/forks.md#f1)) — and the edge serves the live
one on disk.

## What the merging stream has to decide

Probably: **the edge's scanner generates the R2 index too** (run over the master tree before
upload, or over listed bucket keys), so there is ONE scanner and ONE hash recipe. That keeps the
`art gc` relationship intact by making the edge's per-stem hash the only one anyone compares.

It is deliberately not decided here
([F8](../../../../work/2026-08-04-content-toml-only/forks.md#f8)): R2 mode has never run in this
repo — there are no bucket credentials — so any choice made now would be architecture that cannot
be tested. Decide it in the stream that makes R2 mode real.
