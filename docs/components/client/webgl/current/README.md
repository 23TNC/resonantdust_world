# `client/webgl` — current

_What the renderer actually does today. Last updated: 2026-07-31 · verified @ a934b64a._

## It renders UNLIT

The display blit is `albedo.rgb × alpha`. There is no lighting: no lightmap, no shadows, no ambient
term, no ambient occlusion, no emissive, no decay/flicker glow. A full-brightness world is the
**deliberate** resting state, not a bug and not a degraded fallback —
[`work/2026-07-31-lighting-strip`](../../../../work/2026-07-31-lighting-strip/forks.md#f1) chose it so
the seam is obvious rather than looking like something is broken.

## The frame

**One draw in the steady state** — the display blit over the G-buffer composites. **0.028 ms/frame**
at the `focus=100,50&zoom=1` fixture (median of 5 × 60 frames, `gl.finish()` at both ends). The
G-buffer bakes are dirty-gated and idle once the scene has settled.

For scale: the lighting system that was removed cost **0.508 ms static / 0.675 ms with a moving
light** — about 91 % of the frame.

## What is available at the lighting seam

A replacement attaches between the G-buffer bake and the display blit. Already produced per frame,
composited on the fixed 32×16 slot grid, cold (static) and warm (movers) tiers:

| channel | carries |
|---|---|
| `albedo` | base colour |
| `normal` | per-texel surface normal (generated by the art pipeline; **currently unread**) |
| `zdepth` | `B` = the painter's key `0x80 \| (baseRow & 0x7f)`, which resolves warm-over-cold per pixel; `R` relayed the emissive mask |
| `surface` | `R` presence, `G` ambient occlusion (**currently unread**), `B` alpha/coverage |

The art pipeline still generates **normal and depth maps** for every master. Nothing consumes them —
kept deliberately, because any lighting model worth building wants a surface normal and regenerating
the corpus is hours of GPU time.

## What was removed, and where the replacement is designed

`shadowGather.ts` and `coldShadowData.ts` (4 348 lines), ~99 MiB of render targets, and the whole
unified data texture with every band on it. The successor is designed in
[`intent/2026-07-31-rework.md`](../../../../intent/2026-07-31-rework.md) and built by
[`work/2026-07-31-lighting-rework`](../../../../work/2026-07-31-lighting-rework/README.md).
